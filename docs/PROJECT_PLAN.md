- [x] 12 类规则、28 项检查的可配置规则集。

- [x] 严重等级、状态策略与配置校验。

## 验收标准

- 干净检出后，测试能自行生成临时 fixture，不依赖仓库内 `data/raw`。
- 28 项检查可执行；缺列时后续规则失败被隔离，不终止整次运行。
- 基线样例结果：8 通过 / 20 失败，35 条 issue，31 high / 4 medium / 0 low。
- 问题 key 不包含动态 message/metric；重复运行不会因比率轻微变化而误关闭/重开。
- 部分配置运行只关闭本次执行 check_id 范围内的旧问题。
- 状态不会在检查失败时误报 passed；`fail_on_high` 生效。
- CSV 中以 `= + - @` 开头的值被安全转义。
- HTML 报告可独立打开，不依赖外部前端资源。
- 所有 pytest 测试通过。
